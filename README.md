# UoH GPA Calculator

A clean, interactive, and feature-rich web application built to simplify academic tracking and planning for the student community at the University of Haripur. This application goes beyond basic calculations, providing students with utility tools to dynamically forecast and plan their academic goals.

The application is built using **Python** and is fully live and deployed on **Render**.

🔗 **Live Demo:** 

## 🚀 Key Features

* **Core GPA/CGPA Calculator:** An intuitive interface to calculate semester GPA and cumulative CGPA seamlessly by entering subject names, marks, and credit hours.
* **Target Finder:** A specialized planning tool where students can select academic goals (e.g., Dean's List or Good Standing) to instantly find the exact marks required per subject.
* **What-If Simulator:** A dynamic forecasting tool that calculates the precise GPA needed in upcoming semesters to maintain or achieve a specific target CGPA.
* **HEC & UoH Grading Scale:** Fully integrated point mapping compliant with the University of Haripur and HEC Pakistan grading systems, featuring a quick marks-to-grade converter.
* **Result History:** A local calculation history layout allowing students to view and track their previous inputs effortlessly.

## 🛠️ Tech Stack

* **Backend/Logic:** Python
* **Deployment:** Render
* **UI/UX Design:** Modern, clean, and fully responsive layout optimized for both desktop and mobile views.

## 📝 How to Use

1. Navigate to the live link.
2. Select whether you want to calculate **GPA** or **CGPA**.
3. Input your subject names, marks (0-100), and respective credit hours, then click **Calculate**.
4. Use the top navigation bar to access advanced tools like the **Target Finder** or **What-If Simulator** to plan your future semesters.
